# Personlig klassplanering

Läs `INSTALLATION.md` för hela guiden. Börja med mappen `webb/`: där finns färdiga filer för GitHub Pages. Kör SQL-filerna i Supabase, ge kontot behörighet och fyll i två publika värden i `webb/config.js`.

Källkod för framtida ändringar finns i `source/`. Bygg med Node 22 eller senare: `npm install`, `npm run check`, `npm run build`. Inga byggkommandon behövs för den första uppladdningen.

Läs `TESTRESULTAT.md` för verifiering och kvarvarande kontroller.
